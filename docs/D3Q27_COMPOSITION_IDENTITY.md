# 三次chartの合成が九次になる構造 — Q012g3の解釈用補足

## 係数の規約

実座標xとriを用い、既存のTaylor多項式を線形写像Vと対称な双線形・三重線形写像B, Tで

```text
W3(x) = f* + V(x) + B(x,x) + T(x,x,x)
R3(tu) = t r1 + t^2 r2 + t^3 r3
B = (1/2) D^2 W(0),  T = (1/6) D^3 W(0)
```

と表す。ここでの微分は対応する多項式の微分であり、IEEE評価コードの微分との同一視ではない。
r2とr3にも、既存の縮約写像のTaylor係数が既に含まれている。
`physical_path`のr2は`0.5*G2[u,u]`、r3は`reduced_cubic(u)`であり、追加の階乗を掛けない。
既存のsparse monomial格納係数も微分そのものではなく、多項式係数である。
ここでのB/Tはその斉次多項式に対応する対称多重線形写像であり、格納行をそのままB/Tの成分と取り違えない。

以下では`Vi=V(ri)`、`Bij=B(ri,rj)`、`Tijk=T(ri,rj,rk)`と略記する。

## 合成係数の全表

`W3(R3(tu)) = sum_{n=0}^9 t^n Jn`の係数は次の通り。

| n | Jn |
|---|---|
| 0 | `f*` |
| 1 | `V1` |
| 2 | `V2 + B11` |
| 3 | `V3 + 2 B12 + T111` |
| 4 | `2 B13 + B22 + 3 T112` |
| 5 | `2 B23 + 3 T113 + 3 T122` |
| 6 | `B33 + 6 T123 + T222` |
| 7 | `3 T133 + 3 T223` |
| 8 | `3 T233` |
| 9 | `T333` |

多重線形性で各引数からr1/r2/r3を選び、次数和がnの組を集めた。
対称性により同一になる項の置換数が係数2/3/6となる。これは微分の階乗とは別の数である。
例えばJ6のT項は、次数組(1,2,3)の全6置換と(2,2,2)の1通りからなる。
線形3組、双線形9組、三重線形27組、定数1組の計40組が、表の20種類の項へまとまる。

## 診断に使えること・まだ言えないこと

- W2とR2ならT=0かつr3=0で、最高次の合成項の候補はJ4=B22である。
- W3に二次までの内部経路を入れた場合でも、r3=0だけで六次項の消失は保証されない。J6=T222が項として残る。
  特殊なtensorや方向ではその値が0になることもあり、全方向で非零という主張ではない。
- 完全な三次同士ではJ5/J6にも複数の由来がある。高次の欠陥が観測されたことだけから、G3一項の誤りとは決められない。
- Q012g3の欠陥係数は`Cn = [Phi(W3(tu))]_n - Jn`である。合成表だけからCnの大きさや符号は決まらない。
  写像側の係数と、有理式の残りも比較する必要がある。
- 各Cnのnormを足した値は、欠陥normではない。既存の符号付きGram交差項を保持して比較する。
- 既存の丸め済み入力に対する形式的な多項式の恒等式であり、IEEE計算の演算順序を変えてもbitwise一致するという主張ではない。
  この表を使って稼働中の評価器を書き換えない。

33³の登録反例index 16・振幅.032では、欠陥予測に六次まで含めると四次までよりvector誤差が小さくなった。
上の表はそのような高次項が三次chartでも生じる構造を示すが、同反例でどのB/T項が支配的かを測ったものではない。
個別項のnormだけを用いた原因確定、未完了65³やmain960 caseへの一般化、新しい受理gateの追加は行わない。
